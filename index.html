Poggram

A desktop file explorer whose storage is a private Telegram channel — virtual folders, live search and streaming playback over an archive only this app writes to.

Download for Windows View source

Portable — extract and run. No installer, no Python needed.

What it is

Your files physically live in Telegram, as messages in a private supergroup. Poggram is the local index and interface that makes them behave like files: a folder tree, search, thumbnails, versioning and a Trash — none of which a chat gives you.

Nothing passes through a third party. The app talks to Telegram directly as your own account, and the index sits in a local database beside it.

Features

Explorer, not a chat

Folder tree, breadcrumbs, grid and list views, multi-select, context menus, drag-and-drop upload, Trash with restore.

Streams instead of downloading

Video and audio play through range requests served from Telegram, rather than downloading first.

Files past Telegram's limit

Large files are split into chunks on upload — a 16 GB file becomes eight 2 GB parts, or four 4 GB parts with Premium — and merged back on download.

Live search

Scoped to the folder you have open and everything beneath it, in realtime without slowdown.

Versions

Upload over an existing file and keep its history, with restore.

Folder sync

Watch a local folder and upload new files automatically, one at a time.

Resumable transfers

Pause and continue, and pick up again after a restart mid-upload.

Rebuildable

The index itself is backed up into the archive, so a new machine can restore from Telegram alone.

Hide to tray

Closing the window keeps transfers and sync running in the background.

Getting started

  1. Get Telegram API keys. Sign in at my.telegram.org, open API development tools, and copy the api_id and api_hash. Poggram acts as your own account, so it can't create these for you.
  2. Download and extract the release, then run Poggram.exe.
  3. Sign in. In Settings, paste the keys and your phone number, press Connect, then enter the code Telegram sends you.
  4. Create the archive. Press Create supergroup — that private group is where your files will live.

Prefer running from source?

git clone https://github.com/phuong-fang/Poggram
cd Poggram
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pythonw app.py

Worth knowing

Windows only currently

The interface runs on WebView2, which ships with Windows 11.

Early release

0.1.0 has been used daily against a real account, but by one person on one machine. Keep anything irreplaceable backed up elsewhere.

Don't abuse it

Poggram is a client for your own account, so Telegram's ToS apply.

Portable by default

Everything local sits in a data folder next to the executable. Move it and your vault moves with it; delete it and no trace remains.
